##  Overview  
This project is a **Retrieval-Augmented Generation (RAG)** chatbot designed to answer queries based on uploaded documents. It leverages:

- **Ollama’s Mistral model** (local LLM inference)  
- **FAISS** for efficient semantic retrieval via embeddings  
- **Streamlit** for user-friendly, interactive streaming UI  
- **Chunking logic** that maintains context and metadata (file names + page numbers)  
- **Transparent sourcing** with answers followed by source references

---

##  Features  
- Upload documents: PDF, TXT, DOCX  
- Context-aware chunking: 200-word segments with 50-word overlap  
- Embeddings via `all-MiniLM-L6-v2` for semantic search  
- Vector search powered by FAISS  
- Configurable parameters: Temperature, Chunk Size, MMR Diversity  
- Streaming answers generated by Ollama’s Mistral model  
- Each answer includes a clean response followed by a list of source documents  
- Modular code architecture for easy customization

##  Installation & Setup

1. **Clone the repository**
    ```bash
    git clone https://github.com/harshsam29/RAG_ChatBOT_Assignment.git
    cd RAG_ChatBOT_Assignment
    ```

2. **Set up a Python environment**
    ```bash
    python -m venv venv
    source venv/bin/activate         # macOS/Linux
    venv\Scripts\activate            # Windows
    ```

3. **Install dependencies**
    ```bash
    pip install -r requirements.txt
    ```

4. **Install and pull the Ollama model**
    ```bash
    ollama pull mistral
    ```

5. **Run the chatbot app**
    ```bash
    streamlit run app.py
    ```

##  App Usage Walkthrough

Once the app launches in your browser:

1. **Sidebar Configuration**  
   - Set **Temperature** (responsiveness creativity vs. accuracy)  
   - Adjust **Chunk Size** (text grouping granularity)  
   - Modify **MMR Diversity** (retrieval variety vs. redundancy)

2. **Upload Document**  
   Support for PDF/TXT/DOCX. The app automatically chunks, embeds, and builds the FAISS index.

3. **Query Chat Interface**  
   Ask your question in the input box. The bot:
   - Streams a concise, factual answer
   - Lists the relevant sources (filename + page number) below

4. **Chat History**  
   Keep context and rerun queries without reprocessing.
